@Composable
fun Greeting(name: String) {
  var expanded by remember { mutableStateOf(false) }
  ElevatedCard(onClick = { expanded = !expanded }) {
    ListItem(headlineContent = { Text("Hola, $name") })
    AnimatedVisibility(expanded) {
      Text("Plataforma Android completa • 211 HTMLs", modifier = Modifier.padding(16.dp))
    }
  }

Cómo usar la plataforma

  1. Abre index.html sin servidor (file://) o sirve con npx serve .
  2. Navega por Tracks → Módulos → Lecciones. Cada nivel tiene HTML5 completo.
  3. Completa el pipeline: node generate.js regenera los 211 HTMLs desde este único generador (estructura implícita en código).
  4. Valida: todos los HTMLs son semánticos y accesibles. Usa el buscador lateral para filtrar.
