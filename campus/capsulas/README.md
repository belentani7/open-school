# Capsulas diarias

> Indice educativo: [INDICE-EDUCATIVO.md](../../INDICE-EDUCATIVO.md)

## Que son

Una **capsula** es una pieza corta de contenido diario: un concepto, una practica o una idea,
estudiada en pocos minutos. El objetivo es **constancia sobre intensidad**: quien hace una
capsula al dia avanza mas que quien intenta estudiar horas un domingo.

## Formato

Un archivo Markdown por dia, nombrado `YYYY-MM-DD.md`.

## Contenido actual

22 capsulas, del **2026-09-08** al **2026-09-29**. Se acumulan: no se borran.

## Como se usan

1. Se lee la capsula del dia.
2. Si el tema engancha, se profundiza con el curso correspondiente.
3. Se anota lo aprendido antes de pasar a la siguiente.

## Por que importa

Muchas personas que usan estas plataformas no tienen tiempo libre continuo. La capsula
respeta esa realidad: cinco minutos hoy valen mas que dos horas que nunca llegan.
