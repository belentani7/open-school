Concurrencia y virtual threads

Objetivo: aplicar concurrencia y virtual threads mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

Modelo de ejecución

Un hilo puede intercalarse con otros. Una operación read-modify-write no es atómica aunque sus componentes parezcan simples. La visibilidad entre hilos requiere sincronización, volatile para ciertos casos o primitivas concurrentes.

Virtual threads en Java 21

Los hilos virtuales facilitan grandes cantidades de tareas bloqueantes, especialmente I/O. No aceleran automáticamente cálculos CPU-bound. No necesitan un pool limitado por hilos, pero los recursos escasos, como conexiones de base de datos, deben seguir teniendo límites.

Cancelación y aislamiento

Usa ExecutorService con cierre controlado y timeouts. Propaga interrupciones o restaura el flag cuando no puedas propagarlas. Evita esperar indefinidamente en Future.get. No compartas estado mutable sin una política explícita.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import java.util.concurrent.*;
public class Main {
    public static void main(String[] args) throws Exception {
        try (var pool = Executors.newVirtualThreadPerTaskExecutor()) {
            var result = pool.submit(() -> "lesson ready");
            System.out.println(result.get(2, TimeUnit.SECONDS));
        }
    }
}

Laboratorio práctico

Simula 20 tareas que esperan 100 ms; limita el acceso a un recurso simulado a cuatro operaciones mediante Semaphore. Mide tiempo con System.nanoTime y garantiza release en finally.

Solución y criterios de aceptación

El tiempo no debe interpretarse como benchmark definitivo. Los permisos deben liberarse incluso cuando falla la tarea. Un límite de cuatro protege el recurso aunque haya veinte hilos virtuales.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.
