Streams, funciones y procesamiento de datos

Objetivo: aplicar streams, funciones y procesamiento de datos mediante conceptos, código de referencia, práctica y verificación.

Conceptos y decisiones

Pipelines

Un stream representa una secuencia de operaciones, no una estructura que almacena datos. filter, map y sorted son intermedias; collect, count y reduce son terminales. Las intermedias se ejecutan de forma perezosa cuando una terminal consume el pipeline.

Transformaciones puras

Evita modificar una colección externa desde map o filter. Las funciones sin efectos secundarios facilitan pruebas y razonamiento. Un stream no se reutiliza tras una operación terminal. Usa bucles cuando sean más claros.

Agrupación y reducción

Collectors.groupingBy agrupa por una clave y counting cuenta elementos. reduce requiere una operación asociativa para paralelismo correcto. El paralelismo puede empeorar tareas pequeñas o con I/O; no lo actives sin medición.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import java.util.*;
import java.util.stream.*;
public class Main {
    record Lesson(String topic, int minutes) {}
    public static void main(String[] args) {
        var lessons = List.of(new Lesson("Java", 30),
            new Lesson("SQL", 20), new Lesson("Java", 45));
        var totals = lessons.stream().collect(
            Collectors.groupingBy(Lesson::topic,
                Collectors.summingInt(Lesson::minutes)));
        System.out.println(totals);
    }
}

Laboratorio práctico

Filtra lecciones de más de 25 minutos, agrúpalas por tema y calcula duración total. Añade una prueba de lista vacía y otra de duplicados.

Solución y criterios de aceptación

filter(l -> l.minutes() > 25) antes de groupingBy produce Java=75 y omite SQL en el ejemplo. Una lista vacía produce un mapa vacío.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.

Autoevaluación

¿Cuándo se ejecuta normalmente filter?

Solución razonadaAl consumirlo con una terminal. Las operaciones intermedias son lazy.
¿Qué exige una reducción paralela correcta?

Solución razonadaUna operación asociativa. La agrupación de resultados parciales debe ser válida.
