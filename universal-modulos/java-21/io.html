Archivos, NIO y fronteras de confianza

Objetivo: aplicar archivos, nio y fronteras de confianza mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

Path y Files

Path representa una ruta sin abrirla. Files permite leer, escribir y consultar atributos. Usa UTF-8 explícito cuando el formato lo requiere. Evita readAllBytes en archivos de tamaño arbitrario; un stream limita el consumo de memoria.

Rutas seguras

normalize elimina segmentos redundantes, pero no resuelve enlaces simbólicos. toRealPath resuelve una ruta existente. Comprueba que el archivo real permanece bajo la raíz real y aplica una lista de extensiones admitidas. Un servidor local no debe compartir automáticamente carpetas privadas.

Escritura robusta

Escribe un archivo temporal en el mismo directorio y muévelo al destino tras validar el contenido. ATOMIC_MOVE puede no estar disponible: define el tratamiento de ese caso. No registres rutas privadas innecesariamente; separa los errores de acceso de los de formato.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import java.nio.file.*;
import java.io.IOException;
public class Main {
    static Path resolveFile(Path directory, String name) throws IOException {
        Path root = directory.toRealPath();
        Path file = root.resolve(name).normalize().toRealPath();
        if (!file.startsWith(root) || !Files.isRegularFile(file))
            throw new IOException("Outside permitted directory");
        return file;
    }
}

Laboratorio práctico

En un directorio temporal, crea lesson.html. Verifica la ruta válida, una ruta inexistente y una ruta hacia un archivo exterior que tú mismo hayas creado para la prueba. No uses archivos personales.

Solución y criterios de aceptación

El archivo existente dentro de root pasa. El inexistente genera IOException; la ruta exterior real no empieza por root. En producción, añade controles frente a cambios concurrentes y enlaces no confiables.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.
