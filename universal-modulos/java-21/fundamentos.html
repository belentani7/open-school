Conceptos y decisiones

JDK, compilador y JVM

Java no se ejecuta directamente como texto: javac transforma el código en bytecode y la JVM lo carga. El JDK contiene las herramientas de compilación y ejecución. Un archivo público Main.java debe declarar una clase pública Main. Comprueba java -version y javac -version antes de empezar; ambos deben apuntar a la versión prevista.

Tipos y representación

int representa enteros de 32 bits; long amplía el rango a 64 bits. double aproxima números reales y no es adecuado para dinero exacto. boolean modela decisiones; String es una referencia inmutable. La división entera descarta la fracción: 7 / 2 produce 3. Usa BigDecimal o céntimos enteros para importes.

Control de flujo y métodos

Una condición selecciona un camino; un bucle repite mientras su condición sea cierta. Un método encapsula una operación y declara sus parámetros y resultado. Los parámetros se pasan por valor, incluso cuando ese valor es una referencia a un objeto. Prefiere funciones pequeñas y nombres que describan su propósito.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

public class Main {
    static long totalCents(int units, long priceCents) {
        if (units < 0 || priceCents < 0)
            throw new IllegalArgumentException("Negative amount");
        return Math.multiplyExact(units, priceCents);
    }
    public static void main(String[] args) {
        System.out.println(totalCents(3, 199));
    }
}

Laboratorio práctico

Calcula el importe de una cesta con 3 productos de 199 céntimos. Compila Main.java y comprueba 597; prueba también cero, un valor negativo y un desbordamiento.

Solución y criterios de aceptación

El resultado es 597 céntimos. El cero es válido; un precio negativo provoca IllegalArgumentException y un producto fuera del rango long provoca ArithmeticException.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.
