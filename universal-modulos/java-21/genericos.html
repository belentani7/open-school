Genéricos y contratos de tipos

Objetivo: aplicar genéricos y contratos de tipos mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

Parámetros de tipo

List<String> impide insertar un Integer por error de compilación. Los genéricos son invariantes: List<Integer> no es List<Number>. Evita tipos raw, que eliminan garantías del compilador.

Bounded wildcards

? extends T permite leer valores como T, pero no añadir un T arbitrario. ? super T permite escribir T en una colección que admite T o un supertipo. PECS resume el criterio: producer extends, consumer super.

API de dominio

Optional expresa ausencia en un resultado singular; no debe sustituir toda validación ni envolverse en listas sin motivo. Define una clase genérica solo cuando la variación del tipo sea real. La información genérica se borra en gran medida en ejecución, por lo que no puedes construir new T() directamente.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import java.util.*;
public class Main {
    static double sum(List<? extends Number> values) {
        double total = 0;
        for (Number n : values) total += n.doubleValue();
        return total;
    }
    static void append(List<? super Integer> out, int value) {
        out.add(value);
    }
    public static void main(String[] args) {
        System.out.println(sum(List.of(1, 2, 3)));
    }
}

Laboratorio práctico

Implementa una función que copie elementos de una lista productora a una lista consumidora. Prueba copiar Integer a Number y explica por qué el caso inverso no es seguro.

Solución y criterios de aceptación

Firma: static <T> void copy(List<? extends T> from, List<? super T> to). Itera from y añade cada elemento a to. No uses casts ni raw types.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.

Autoevaluación

¿Cuál es la lista productora de Number?

Solución razonadaList<? extends Number>. extends proporciona elementos legibles como Number.
¿Qué expresa Optional.empty()?

Solución razonadaAusencia de un valor. Optional modela presencia o ausencia.
