Pruebas automatizadas y Maven

Objetivo: aplicar pruebas automatizadas y maven mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

Pirámide de pruebas

Las pruebas unitarias verifican una unidad aislada; las de integración comprueban colaboraciones reales; las de extremo a extremo recorren el producto. Elige el nivel que reproduce el riesgo: la validación de un record no requiere una base de datos.

JUnit y casos límite

Usa arrange, act, assert. Comprueba comportamiento observable, no detalles privados de implementación. Incluye límites, entradas inválidas y resultados vacíos. assertThrows verifica el contrato de error.

Maven reproducible

El POM declara dependencias, plugins y versión de Java. mvn verify ejecuta fases anteriores y verificaciones configuradas. Fija versiones de plugins y dependencias; evita descargas no confiables. No cambies una prueba para ocultar un fallo real.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;
class CourseTest {
    @Test void rejectsInvalidHours() {
        assertThrows(IllegalArgumentException.class,
            () -> new Course("java", "Java", 0));
    }
    @Test void acceptsValidCourse() {
        assertEquals(3, new Course("java", "Java", 3).hours());
    }
}

Laboratorio práctico

En un proyecto Maven con JUnit Jupiter 5 y el Course del módulo de objetos, añade casos de título vacío, horas negativas y curso correcto. Ejecuta mvn verify.

Solución y criterios de aceptación

Los casos inválidos deben provocar IllegalArgumentException; los correctos conservan los valores. Usa un plugin Surefire compatible con JUnit 5 y configura el compilador para release 21.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.

Autoevaluación

¿Qué fase verifica el proyecto además de las pruebas configuradas?

Solución razonadamvn verify. verify incluye las fases anteriores del ciclo Maven.

Solución razonadaComportamiento observable. El comportamiento es el contrato relevante.
