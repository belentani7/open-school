Colecciones, igualdad y complejidad

Objetivo: aplicar colecciones, igualdad y complejidad mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

List, Set y Map

List mantiene posiciones y permite duplicados. Set representa pertenencia y elimina duplicados según su contrato de igualdad. Map relaciona claves y valores; no es una Collection. Selecciona la estructura a partir de las consultas que necesitas, no por costumbre.

Igualdad y claves

equals y hashCode deben ser coherentes: si dos objetos son iguales, su hash debe ser igual. No cambies campos que participan en la igualdad mientras un objeto es clave de HashMap. String y records de componentes inmutables son buenas claves.

Coste y orden

ArrayList permite acceso indexado rápido y append amortizado constante; insertar al inicio desplaza elementos. HashMap ofrece búsqueda esperada constante, no garantía absoluta; TreeMap mantiene orden con coste logarítmico. LinkedHashMap conserva orden de inserción. Mide antes de optimizar.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

import java.util.*;
public class Main {
    public static void main(String[] args) {
        var frequency = new LinkedHashMap<String,Integer>();
        for (String item : List.of("java", "sql", "java"))
            frequency.merge(item, 1, Integer::sum);
        System.out.println(frequency);
    }
}

Laboratorio práctico

Construye un índice de frecuencia de etiquetas de cursos, ignora duplicados dentro de cada curso y muestra las tres etiquetas más frecuentes. Decide qué estructura usar en cada etapa.

Solución y criterios de aceptación

Usa Set.copyOf para etiquetas únicas por curso, Map.merge para contar y ordena las entradas por valor descendente, con la clave como desempate estable.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.

Autoevaluación

¿Qué contrato deben respetar equals y hashCode?

Solución razonadaLos objetos iguales tienen el mismo hash. Las colisiones son posibles; la igualdad exige hashes iguales.
¿Qué colección conserva orden de inserción de claves?

Solución razonadaLinkedHashMap. LinkedHashMap define ese orden.
