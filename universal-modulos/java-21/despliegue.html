Entrega, contenedores y observabilidad

Objetivo: aplicar entrega, contenedores y observabilidad mediante conceptos, código de referencia, práctica y verificación.

TeoríaEjemploLaboratorioEvaluación

Conceptos y decisiones

Artefacto verificable

El pipeline debe instalar dependencias fijadas, compilar, probar y crear un artefacto identificable por commit. Un build exitoso no garantiza arranque: prueba una instancia real y su healthcheck. No subas target ni credenciales.

Contenedores y entornos

Un contenedor de Java puede construirse con una etapa JDK/Maven y ejecutarse con JRE. Usa usuario sin privilegios y configuración inyectada. Una web estática puede alojarse en Vercel o Pages; el servicio JVM requiere un runtime compatible. No confundas un HTML publicado con una API Java desplegada.

Operación y rollback

Registra duración, errores y disponibilidad sin datos personales. Define una versión anterior recuperable y valida migraciones antes de cambiar producción. Comprueba HTML, CSS, JS, API y health por separado. Documenta qué está realmente operativo y qué no.

Ejemplo comentado en el módulo

Lee el código y relaciónalo con la teoría. Los ejemplos con bibliotecas externas requieren el proyecto indicado; los fragmentos no se presentan como aplicaciones autónomas.

FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app
COPY pom.xml .
COPY src src
RUN mvn -B verify
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=build /app/target/app.jar app.jar
USER 10001
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar"]

Laboratorio práctico

Configura finalName=app en Maven o ajusta COPY al nombre real del JAR. Construye la imagen en un entorno con Docker, arranca con datos de prueba y verifica health y catálogo. Etiqueta el artefacto con su commit.

Solución y criterios de aceptación

Ejecuta las pruebas antes de construir. Configura el servidor para escuchar en la interfaz del contenedor, sin credenciales por defecto. El rollback vuelve al artefacto anterior y requiere compatibilidad del esquema.

Guarda el código, el comando utilizado y el resultado de las pruebas como evidencia personal.

Autoevaluación

¿Qué demuestra realmente un HTTP 200 de index.html?

Solución razonadaQue esa ruta HTML responde. Se deben comprobar independientemente las capas.
¿Cuál es una medida de seguridad de contenedor?

Solución razonadaUsar un usuario sin privilegios. Limita las capacidades del proceso.
