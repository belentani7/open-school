2. Evita ejecutar dos veces

La idempotencia significa que aplicar una operación repetidamente produce el mismo efecto final que aplicarla una vez. Para crear recursos, una clave de idempotencia aceptada por el servidor puede impedir duplicados. Si el servicio no la admite, consulta el resultado anterior antes de reintentar.
