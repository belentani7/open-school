Actividades transferibles

  • Dibuja en papel un formulario con nombre opcional y correo necesario. Escribe la etiqueta de cada campo y la ayuda contextual sin usar color como única señal.
  • Navega con Tab y Shift+Tab por una página de práctica. Anota cualquier elemento interactivo que no tenga foco o cuya posición resulte confusa.
  • Reescribe “Error de formulario” como un mensaje concreto: “Escribe un correo con @ y un dominio, por ejemplo nombre@ejemplo.com”.

Usa únicamente ejemplos ficticios; no incluyas documentos ni datos personales reales.
