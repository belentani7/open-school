# Open School

Campus estático abierto. La edición pública recuperada contiene 413 materiales indexados. `cursos.html` es la biblioteca accesible sin JavaScript; con JavaScript permite buscar sin distinguir acentos, filtrar por categoría, guardar favoritos y marcar materiales completados. El progreso se conserva en el navegador, sin cuenta. `catalog.json` es el índice de referencia.

## Uso

`python -m http.server 8080` y abre `http://localhost:8080/cursos.html`.

## Alcance

La carpeta legacy de origen, incluida open-school-private, queda preservada localmente y no se publica en esta edición. No se afirma que sus archivos sean cursos únicos ni públicos. El número de materiales indexados no equivale a una certificación ni a una cifra de cursos completos.
