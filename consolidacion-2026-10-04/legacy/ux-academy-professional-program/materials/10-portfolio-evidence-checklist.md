# Portfolio Evidence Checklist

Use this checklist before publishing or sharing a case. Every assertion must be traceable to an approved artifact, a recorded observation, or clearly labeled as a hypothesis.

| Area | Check | Evidence location |
|---|---|---|
| Context | The problem, audience, constraints and role are clear |  |
| Research | Methods, consent approach, findings and limitations are stated |  |
| Decisions | Alternatives and selection criteria are visible |  |
| Design | Flows, UI states, accessibility and responsive behavior are represented |  |
| Evaluation | Tasks, observations, results and iteration are traceable |  |
| Impact | Metrics are real, scoped and attributed; unknowns are declared |  |
| Privacy | Personal data, confidential material and third-party content are removed or permitted |  |
| Accessibility | Case structure, images, contrasts and links are accessible |  |
