# Design System Specification Template

## Foundations

List primitive and semantic tokens for color, typography, spacing, shape, elevation, motion, and responsive behavior.

## Component record

| Field | Definition |
|---|---|
| Purpose | The task this component supports |
| Anatomy | Required and optional parts |
| Properties | Variant axes and allowed values |
| States | Default, hover, focus, pressed, disabled, loading, error |
| Accessibility | Name, role, keyboard, focus, contrast, feedback |
| Content | Voice, length, and localization rules |
| Governance | Owner, change proposal, version and deprecation path |
