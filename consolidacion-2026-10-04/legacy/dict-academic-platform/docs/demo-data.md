# Datos de demostración

Las vistas de demostración de D.I.C.T. muestran un expediente ficticio con 84 CA, proyectos de ejemplo y el identificador `DCT-DEMO-8F21`. Estos datos sirven exclusivamente para comprobar jerarquía, navegación, transcript, certificados internos y portfolio durante el desarrollo. No se insertan como datos personales, no pertenecen a una persona real y no constituyen una reseña, calificación verificada ni credencial emitida.
