# latam-europa

Plataforma pública de orientación migratoria verificada para personas latinoamericanas que migran a España

## Stack

- Primary language: TypeScript
- Node project (`package.json` present)

## Getting started

```bash
git clone https://github.com/belentani7/latam-europa.git
```

```bash
npm install
npm run dev
```
