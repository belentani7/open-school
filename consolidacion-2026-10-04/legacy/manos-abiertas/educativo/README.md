# Material Educativo para Optimización Web Lighthouse

Este material está diseñado para acompañar las guías de optimización y ayudarte a comprender profundamente los conceptos detrás de cada métrica de Lighthouse.

## Estructura del Material

1. **Módulos Teóricos** - Explicaciones detalladas de cada concepto
2. **Preguntas de Autoevaluación** - Para verificar tu comprensión
3. **Ejercicios Prácticos** - Actividades hands-on para aplicar lo aprendido
4. **Tests de Conocimiento** - Evaluaciones más completas
5. **Recursos Adicionales** - Enlaces a documentación oficial y tutoriales

## Cómo usar este material

1. Comienza con el módulo que corresponda a tu área de mayor necesidad (basado en tu informe Lighthouse)
2. Lee la explicación teórica
3. Responde las preguntas de autoevaluación
4. Completa los ejercicios prácticos
5. Realiza el test de conocimiento
6. Aplica lo aprendido a tu sitio web usando las guías de optimización

## Módulos Disponibles

- [Performance](performance.md) - Optimización de velocidad de carga
- [Accessibility](accessibility.md) - Accesibilidad web para todos los usuarios
- [Best Practices](best-practices.md) - Prácticas recomendadas de desarrollo web
- [SEO](seo.md) - Optimización para motores de búsqueda

Cada módulo sigue la misma estructura:
1. Conceptos clave
2. Explicación detallada
3. Preguntas de autoevaluación (con respuestas al final)
4. Ejercicios prácticos
5. Test de conocimiento
6. Recursos adicionales
