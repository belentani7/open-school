# Investigación de repositorios GitHub para Manos Abiertas

Fecha de consulta: 4 de agosto de 2026.

## Resultado

Se localizaron **107 repositorios candidatos**, deduplicados mediante búsquedas de GitHub API en once áreas: despliegue Next.js/Netlify, PWA, local-first, accesibilidad, educación, comunidad, privacidad, pruebas, rendimiento, internacionalización y derechos digitales.

Estos repositorios son **referencias de arquitectura y soluciones**. No se añadió código externo automáticamente: cada incorporación debe pasar revisión de licencia, seguridad, mantenimiento, compatibilidad con Netlify y utilidad para la comunidad latinoamericana.

## Soluciones aplicadas al proyecto

- Despliegue Netlify con salida Next.js compatible y rutas serverless.
- Foro comunitario compartido mediante Netlify Blobs, con validación Zod y limitación básica por IP.
- PWA instalable con manifiesto, iconos y service worker.
- Modo local para tutoría, progreso, exportación/importación y borradores cuando una API no está disponible.
- Catálogo multilingüe de recursos educativos y de derechos.
- Validaciones de lint, TypeScript, build y comprobación HTTP pública.

## Estado pendiente

- Autenticación y perfiles verificados.
- Moderación, denuncia y bloqueo de contenido.
- Persistencia de usuarios y progreso sincronizado.
- Pruebas E2E con Playwright.
- Auditoría WCAG con usuarios reales y lectores de pantalla.
- Política de privacidad, retención y protección de datos revisada legalmente.

## Criterio de selección

La lista prioriza patrones reutilizables; popularidad no equivale a calidad ni implica recomendación de instalar. Para producción se usarán primero documentación oficial, dependencias mínimas y componentes que puedan eliminarse sin bloquear la aplicación.
