# Módulo 5: Automatização e Integração — Nível 01
## Idioma: PT · Dificuldade: Semente
## Tempo estimado: 1 hora

## 🎯 Objetivo do nível
- Reconhecer as tarefas repetitivas que fazemos diariamente em casa e no trabalho.
- Distinguir quais dessas tarefas se podem automatizar e quais não.
- Aprender a descrever uma tarefa como uma sequência de passos.
- Escolher uma tarefa própria para automatizar nos próximos níveis.
- Entender que automatizar começa por observar, não por programar.

## 📖 Vocabulário essencial
| Termo | Explicação em palavras simples |
|---|---|
| Tarefa repetitiva | Um trabalho que se faz uma e outra vez igual: pagar uma conta, rever o correio. |
| Passo | Cada ação concreta dentro de uma tarefa. |
| Sequência | A ordem em que se fazem os passos. |
| Rotina | Um conjunto de tarefas que repetimos na mesma ordem. |
| Automatizável | Que se pode fazer sem a presença de uma pessoa. |
| Decisão | Um momento em que escolhemos entre várias opções. |

## 📚 Lição principal
No nível anterior aprendemos que automatizar é fazer com que uma máquina faça uma tarefa por nós. Hoje vamos dar o segundo passo: aprender a olhar para a nossa própria vida e encontrar as tarefas que se repetem. Porque não se pode automatizar o que não se vê.

Vamos imaginar a cozinha de casa. Todas as manhãs preparamos café: moer, pôr água, ligar a cafeteira. Todos os dias é igual. Essa é uma tarefa repetitiva e, de facto, muitas cafeteiras já se podem programar para que o café esteja pronto a uma determinada hora.

A tarefa repetitiva tem três sinais. Primeiro, faz-se com muita frequência: todos os dias, todas as semanas. Segundo, faz-se igual sempre: mesmos passos, mesma ordem. Terceiro, não precisa de grandes decisões: sabe-se de antemão o que fazer. Quando uma tarefa tem esses três sinais, é uma boa candidata a automatizar.

No escritório encontramos muitas tarefas repetitivas. Rever o correio todas as manhãs, guardar os documentos na mesma pasta, copiar os dados de um papel para uma tabela, enviar o mesmo relatório todas as semanas. São trabalhos que um programa ou uma regra bem posta poderia fazer sozinho.

Mas nem todas as tarefas repetitivas se automatizam igual. Algumas são muito simples: pôr um alarme, guardar um arquivo. Outras são complicadas: preencher um formulário com dados que mudam a cada vez. A regra geral é simples: se os passos são sempre os mesmos, a máquina pode aprendê-los; se os passos mudam consoante o que decidimos, é preciso uma pessoa.

Para automatizar uma tarefa primeiro é preciso descrevê-la. Como quando ensinamos alguém a fazer um prato: primeiro explicamos passo a passo. Ponhamos de exemplo "fazer as compras da semana". Os passos poderiam ser: fazer a lista, ir à loja, comprar, pagar, trazer para casa. Alguns desses passos são automáticos (a lista com modelo), outros precisam de uma pessoa (escolher as frutas frescas).

É preciso evitar a armadilha de automatizar o que não vale a pena. Se uma tarefa a fazemos uma vez por ano, não vale a pena o esforço. Se demora dez segundos, também não. O que vale a pena é automatizar o que fazemos muito e demora tempo. É como na cozinha: compramos uma batedeira porque batemos com frequência, não para um único uso.

Outra coisa importante: muitas tarefas repetitivas são na realidade a soma de várias pequenas. "Pagar a conta da água" é: abrir o correio, encontrar a conta, abrir o banco, fazer a transferência, guardar o comprovativo. Cada passo pode automatizar-se em separado. Começar por um único passo já é um grande avanço.

Quando observarmos a nossa própria semana, vamos encontrar tarefas que fazemos sem pensar. Essas são as melhores para começar: já as conhecemos, já sabemos como se fazem e já temos a ordem. Só falta escrevê-las e pedir à máquina que as repita.

Não é preciso afligir-se. Este módulo é como aprender a semear: primeiro prepara-se a terra, depois escolhe-se a semente, e com o tempo colhe-se. Hoje só preparamos a terra: olhamos, anotamos e escolhemos. O resto virá sozinho.

Uma sugestão: esta semana, sempre que fizeres uma tarefa pela segunda vez, pergunta-te em voz baixa: "isto repete-se?". Se a resposta for sim, anota. Verás que a lista cresce sozinha. E dessa lista sairá a tua primeira automatização.

## 💡 Exemplos práticos
1. **O correio do trabalho.** Luísa revê cinquenta correios todas as manhãs e a maioria são avisos que não precisa de ler. Nos próximos níveis vai aprender a filtrá-los para que só cheguem os importantes.
2. **A lista de compras.** Ramón usa a mesma lista todas as semanas. Ao guardá-la como modelo no telemóvel, não tem de a voltar a escrever: só marca o que já não faz falta.
3. **O relatório semanal.** Carmen copia todas as sextas-feiras os mesmos números para uma folha. É uma tarefa repetitiva perfeita para automatizar mais à frente neste módulo.

## 🛠️ Atividade guiada
Passo 1: Pega no teu papel do nível 0 com as duas colunas e acrescenta uma terceira: "Tarefas que se repetem".
Passo 2: Pensa numa semana normal e escreve cinco tarefas que faças sempre da mesma maneira: pôr o despertador, verificar o correio, regar as plantas, pagar uma conta, fazer café.
Passo 3: Escolhe uma dessas tarefas e escreve os seus passos por ordem, numerados de 1 a 4 ou 5. Por exemplo, pagar a conta da água: 1) abrir o correio, 2) ler a conta, 3) abrir o banco, 4) pagar, 5) guardar o comprovativo.
Passo 4: Sublinha a vermelho os passos que são sempre iguais e a azul os que exigem decidir.
Passo 5: Pensa se essa tarefa passa os três sinais: faz-se com frequência? sempre igual? sem grandes decisões? Anota sim ou não em cada um.
Passo 6: Guarda esta descrição. É o teu "processo de tarefa" e vamos usá-lo nos próximos níveis para construir a automatização.
Passo 7: Repete os passos 2 a 6 com uma tarefa do escritório ou do teu trabalho, se tiveres uma.

## ✍️ Exercícios de autoavaliação
1. Qual é um sinal de que uma tarefa se pode automatizar? a) Que se faça uma vez por ano. b) Que se faça com frequência, sempre igual e sem decisões grandes. c) Que seja muito difícil.
2. O que é o primeiro que se faz para automatizar uma tarefa? a) Comprar um programa. b) Descrevê-la passo a passo. c) Pedir ajuda.
3. Automatiza-se igual uma tarefa simples e uma complicada? a) Sim, sempre. b) Não, as simples automatizam-se antes. c) Não se automatiza nenhuma.
4. Vale a pena automatizar uma tarefa que fazemos uma vez por ano? a) Sim, sempre. b) Não, não compensa o esforço. c) Depende da cor.
5. O que é uma tarefa repetitiva? a) Um trabalho que se faz uma e outra vez da mesma maneira. b) Um trabalho muito divertido. c) Um trabalho de uma só vez.

Respostas: 1-b, 2-b, 3-b, 4-b, 5-a.

## ⚖️ Dimensão ética
- Observar as tuas próprias tarefas é bom; observar as tarefas dos outros para lhes poupar trabalho pode ser útil, mas pergunta antes de mudar a forma de trabalhar de outra pessoa.
- Não automatizes tarefas que os outros gostam de fazer só para seres "eficiente".
- Se automatizares uma tarefa no trabalho, informa a tua equipa: a transparência evita surpresas e erros.
- Anotar as tuas rotinas num papel é seguro; não guardes palavras-passe nem dados sensíveis nessas notas.
- Automatizar uma tarefa não é tirar o trabalho a ninguém: é libertar tempo para coisas mais importantes.

## 🧠 Resumo e ponte
As tarefas repetitivas são as que se fazem com frequência, sempre igual e sem grandes decisões. Para as automatizar é preciso descrevê-las passo a passo e escolher as que valem a pena. Já tens o teu processo de tarefa. No próximo nível vamos aprender a usar os lembretes do telemóvel, a primeira automatização prática que podemos pôr em marcha ainda hoje.
