# Módulo 2: Herramientas sin Código — Nivel 17
## Idioma: ES · Dificultad: Rama
## Tiempo estimado: 4 horas

## 🎯 Objetivo del nivel
- Entender qué es una base de datos y en qué se diferencia de una hoja de cálculo.
- Aprender a crear una base de datos sencilla con IA.
- Usar las vistas para ver los datos como tabla, como tarjetas o como calendario.
- Pedirle a la IA que organice, filtre y entienda tus datos.
- Poner orden en las listas que te importan: socios, stock, contactos.

## 📖 Vocabulario esencial
| Término | Explicación sencilla |
|---------|----------------------|
| Base de datos | Un lugar que guarda datos de forma ordenada, como un gran armario bien clasificado. |
| Registro | Cada persona o cosa de la base de datos, como una ficha del fichero. |
| Campo | Cada tipo de dato de un registro: nombre, fecha, teléfono. |
| Vista | Una manera de ver los datos: como tabla, como tarjetas, como calendario. Es el mismo dato visto distinto. |
| Filtro | Un tamiz: muéstrame solo los datos que cumplen algo, como tamizar harina. |
| Plantilla | Una base de datos ya hecha que alguien diseñó, para no empezar de cero. |

## 📚 Lección principal
En el nivel 11 aprendimos las hojas de cálculo: tablas que calculan. Hoy damos un paso más: las bases de datos. Una base de datos es un lugar que guarda datos de forma ordenada, pero es mucho más potente que una hoja de cálculo. Si la hoja de cálculo es un armario, la base de datos es un almacén: guarda de todo, y siempre encuentras lo que buscas. Y con la IA, crearla y usarla está al alcance de todos.

Entendamos la diferencia. Una hoja de cálculo es como una página de un cuaderno: todo en la misma tabla. Una base de datos es como un armario con fichas: cada persona, cada cosa tiene su ficha, con los mismos campos. Y la magia: puedes ver los mismos datos de muchas maneras, sin tocarlos. Como tabla, como tarjetas, como calendario. Es la misma agua en vasos distintos.

Las herramientas de este nivel son Airtable y las bases de datos nuevas de Google. Son servicios donde creas una base de datos con una plantilla o desde cero, la rellenas y le pides a la IA que la organice. No programas nada: haces clic, arrastras, preguntas. Es como ordenar la despensa: cada cosa en su sitio, y tú sabes dónde está todo.

Pensemos en un ejemplo real: los socios de la asociación. Creas una base de datos con los campos: nombre, teléfono, fecha de alta, cuotas pagadas. Cada socio es un registro. Y ahora la magia: preguntas "¿quién no ha pagado la última cuota?", y la base de datos filtra y te muestra la lista. "¿Quién se ha dado de alta este año?" Filtra. Tienes un armario que responde preguntas.

Otro ejemplo: el banco de alimentos del centro cívico. Una base de datos con los alimentos, la cantidad, la fecha de caducidad. Preguntas "¿qué caduca este mes?" y te lo muestra. "¿Cuántos kilos de arroz tenemos?" Cuenta. La IA se ocupa de los números, y tú de las personas. La base de datos da orden, y tú das calor.

¿Cómo se crea? Abres Airtable, eliges una plantilla o empiezas de cero. Defines los campos: para cada tipo de dato, su sitio. Rellenas los registros: uno por persona o cosa. Y después exploras: la vista de tabla, la de tarjetas, la de calendario. Todo con los mismos datos, cada vista para un momento distinto. Es como tener varias ventanas sobre la misma casa.

¿Y la IA? Hoy las bases de datos traen un asistente. Le preguntas con tus palabras: "resume cuántos socios han pagado", "muéstrame las visitas del mes". La IA convierte tu pregunta en la búsqueda y te responde. Sin fórmulas, sin saber de bases de datos: preguntas, y te entiende. La buena pregunta de nuestros niveles vuelve, ahora para organizar datos.

Una lección importante: el orden importa. Una base de datos solo responde bien si los datos están limpios: la misma fecha en el mismo formato, los nombres sin un espacio al principio, todo en su campo. Es como una receta: si los ingredientes no están en orden, el plato falla. Dedica tiempo a rellenar bien, y la base de datos te lo devolverá durante años.

Hablemos también de para qué NO es una base de datos. No es para escribir cartas, ni para un documento, ni para una presentación. Es para datos: listas, personas, cosas, fechas. Si tienes que calcular, la hoja de cálculo; si tienes que guardar y encontrar, la base de datos; si tienes que explicar, la presentación. Cada herramienta en su sitio, y tú, que las eliges, al mando.

Y una lección de confianza: no tengas miedo a la palabra "base de datos". Suena a técnico, pero detrás está la idea sencilla del armario bien clasificado. Tú sabes clasificar un armario: esto es para los cereales, esto para las latas, esto para las especias. Una base de datos es lo mismo, pero con datos. Y con la IA, ni siquiera necesitas recordar dónde está cada cosa: preguntas.

## 💡 Ejemplos prácticos
1. **Los socios de la asociación**: una base de datos con nombres, teléfonos y cuotas pagadas. Preguntas: "¿Quién no ha pagado este mes?" La base de datos filtra y te da la lista. Nada de cuaderno con nombres tachados.
2. **La despensa del centro**: una base de datos con los alimentos y sus fechas de caducidad. Preguntas: "¿Qué caduca este mes?" Y sabes qué usar primero. Menos desperdicio, más orden.
3. **La lista de cumpleaños**: una base de datos con los cumpleaños de familia y amigas. Los ves en la vista de calendario y ya nunca llegas tarde. Las personas que quieres merecen esa memoria que siempre quisiste tener.

## 🛠️ Actividad guiada
1. Abre Airtable (airtable.com) con tu cuenta.
2. Mira la página principal: busca la sección de plantillas. Observa cuántas bases de datos hay ya diseñadas.
3. Elige una plantilla sencilla: por ejemplo, una lista de contactos o de tareas.
4. Observa la pantalla: mira los campos (nombre, fecha, notas) y los registros.
5. Añade un registro real tuyo: una persona o una cosa que te importe.
6. Cambia la vista: de tabla a tarjetas, a calendario. Mira cómo cambia el mismo dato de aspecto.
7. Pregúntale a la IA: "¿Cuántos registros hay?" o "Muéstrame los de este mes". Pruébalo.
8. Añade un filtro: muestra solo lo que te interesa.
9. Anota en tu cuaderno: ¿qué lista de tu vida merece convertirse en una base de datos?

## ⚖️ Dimensión ética
Una base de datos guarda personas: nombres, teléfonos, fechas. Eso son datos personales, y cuidarlos es una responsabilidad. No metas en una base de datos cosas que no deberían estar, y no la compartas con nadie sin permiso. La lista de la asociación no es para venderla, ni para el chisme: es para servir. Y recuerda que la IA ve lo que tú pones: una base de datos con datos de todos es un tesoro que exige honestidad. Buenos datos, bien usados, para buenos fines.

## 🔓 Herramientas abiertas
- **Airtable** (airtable.com) — la base de datos amable con plantillas, gratuita en su versión básica.
- **Google Tables** (tables.google.com) — la base de datos de Google, sencilla y conectada con la familia de herramientas que conoces.
- **Notion** (notion.so) — un espacio que combina documentos y bases de datos, con una parte gratuita.
- **LibreOffice Base** (libreoffice.org) — la base de datos de código abierto que vive en tu ordenador.
- **NocoDB** (nocodb.com) — una base de datos de código abierto que puedes tener en casa.

## 🧠 Resumen y puente
Una base de datos es un almacén bien clasificado: registros, campos y vistas, con una IA que entiende tus preguntas. Sirve para listas, personas, cosas y fechas; la hoja de cálculo para calcular. Has creado, rellenado y preguntado: ya sabes poner orden en los datos. En el siguiente nivel descubriremos la voz: herramientas que leen, escriben y hablan, para que el ordenador también te escuche.
