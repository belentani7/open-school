# Módulo 2: Ferramentas sem Código — Nível 17
## Idioma: PT · Dificuldade: Ramo
## Tempo estimado: 4 horas

## 🎯 Objetivo do nível
- Perceber o que é uma base de dados e em que se diferencia de uma folha de cálculo.
- Aprender a criar uma base de dados simples com IA.
- Usar as vistas para ver os dados como tabela, como cartões ou como calendário.
- Pedir à IA que organize, filtre e entenda os seus dados.
- Pôr ordem nas listas que lhe importam: sócios, stock, contactos.

## 📖 Vocabulário essencial
| Termo | Explicação simples |
|-------|--------------------|
| Base de dados | Um lugar que guarda dados de forma ordenada, como um grande armário bem classificado. |
| Registo | Cada pessoa ou coisa da base de dados, como uma ficha do ficheiro. |
| Campo | Cada tipo de dado de um registo: nome, data, telefone. |
| Vista | Uma maneira de ver os dados: como tabela, como cartões, como calendário. É o mesmo dado visto de forma diferente. |
| Filtro | Um crivo: mostra-me apenas os dados que cumprem algo, como peneirar farinha. |
| Modelo | Uma base de dados já feita que alguém desenhou, para não começar do zero. |

## 📚 Lição principal
No nível 11 aprendemos as folhas de cálculo: tabelas que calculam. Hoje damos um passo em frente: as bases de dados. Uma base de dados é um lugar que guarda dados de forma ordenada, mas é muito mais poderosa do que uma folha de cálculo. Se a folha de cálculo é um armário, a base de dados é um armazém: guarda de tudo, e encontra sempre o que procura. E com a IA, criá-la e usá-la está ao alcance de todos.

Entendamos a diferença. Uma folha de cálculo é como uma página de um caderno: tudo na mesma tabela. Uma base de dados é como um armário com fichas: cada pessoa, cada coisa tem a sua ficha, com os mesmos campos. E a magia: pode ver os mesmos dados de muitas maneiras, sem os tocar. Como tabela, como cartões, como calendário. É a mesma água em copos diferentes.

As ferramentas deste nível são o Airtable e as bases de dados novas do Google. São serviços onde cria uma base de dados com um modelo ou do zero, preenche-a e pede à IA que a organize. Não programa nada: clica, arrasta, pergunta. É como arrumar a despensa: cada coisa no seu lugar, e você sabe onde está tudo.

Pensemos num exemplo real: os sócios da associação. Cria uma base de dados com os campos: nome, telefone, data de adesão, quotas pagas. Cada sócio é um registo. E agora a magia: pergunta "quem não pagou a última quota?", e a base de dados filtra e mostra-lhe a lista. "Quem aderiu este ano?" Filtra. Tem um armário que responde a perguntas.

Outro exemplo: o banco alimentar do centro cívico. Uma base de dados com os alimentos, a quantidade, a data de validade. Pergunta "o que expira este mês?" e mostra-lhe. "Quantos quilos de arroz temos?" Conta. A IA trata dos números, e você das pessoas. A base de dados dá ordem, e você dá calor.

Como se cria? Abre o Airtable, escolhe um modelo ou começa do zero. Define os campos: para cada tipo de dado, o seu lugar. Preenche os registos: um por pessoa ou coisa. E depois explora: a vista de tabela, a de cartões, a de calendário. Tudo com os mesmos dados, cada vista para um momento diferente. É como ter várias janelas sobre a mesma casa.

E a IA? Hoje as bases de dados trazem um assistente. Pergunta com as suas palavras: "resuma quantos sócios pagaram", "mostre-me as visitas do mês". A IA transforma a sua pergunta na pesquisa e responde. Sem fórmulas, sem saber de bases de dados: pergunta, e ela entende. A boa pergunta dos nossos níveis volta, agora para organizar dados.

Uma lição importante: a ordem importa. Uma base de dados só responde bem se os dados estiverem limpos: a mesma data no mesmo formato, os nomes sem um espaço no início, tudo no seu campo. É como uma receita: se os ingredientes não estiverem em ordem, o prato falha. Dedique tempo a preencher bem, e a base de dados devolver-lhe-á isso durante anos.

Falemos também para que NÃO é uma base de dados. Não é para escrever cartas, nem para um documento, nem para uma apresentação. É para dados: listas, pessoas, coisas, datas. Se tem de calcular, a folha de cálculo; se tem de guardar e encontrar, a base de dados; se tem de explicar, a apresentação. Cada ferramenta no seu lugar, e você, que as escolhe, no comando.

E uma lição de confiança: não tenha medo da palavra "base de dados". Soa a técnico, mas por trás está a ideia simples do armário bem classificado. Você sabe classificar um armário: isto é para os cereais, isto para as latas, isto para as especiarias. Uma base de dados é o mesmo, mas com dados. E com a IA, nem precisa de se lembrar de onde está cada coisa: pergunta.

## 💡 Exemplos práticos
1. **Os sócios da associação**: uma base de dados com nomes, telefones e quotas pagas. Pergunta: "Quem não pagou este mês?" A base de dados filtra e dá-lhe a lista. Nada de caderno com nomes riscados.
2. **A despensa do centro**: uma base de dados com os alimentos e as suas datas de validade. Pergunta: "O que expira este mês?" E sabe o que usar primeiro. Menos desperdício, mais ordem.
3. **A lista de aniversários**: uma base de dados com os aniversários da família e das amigas. Vê-os na vista de calendário e nunca mais chega atrasado. As pessoas que ama merecem essa memória que sempre quis ter.

## 🛠️ Atividade guiada
1. Abra o Airtable (airtable.com) com a sua conta.
2. Olhe para a página principal: procure a secção de modelos. Observe quantas bases de dados já estão desenhadas.
3. Escolha um modelo simples: por exemplo, uma lista de contactos ou de tarefas.
4. Observe o ecrã: veja os campos (nome, data, notas) e os registos.
5. Adicione um registo real seu: uma pessoa ou uma coisa que lhe importe.
6. Mude a vista: de tabela para cartões, para calendário. Veja como o mesmo dado muda de aspeto.
7. Pergunte à IA: "Quantos registos há?" ou "Mostre-me os deste mês." Experimente.
8. Adicione um filtro: mostre apenas o que lhe interessa.
9. Anote no seu caderno: que lista da sua vida merece tornar-se uma base de dados?

## ⚖️ Dimensão ética
Uma base de dados guarda pessoas: nomes, telefones, datas. Isso são dados pessoais, e cuidá-los é uma responsabilidade. Não meta numa base de dados coisas que não deviam estar, e não a partilhe com ninguém sem autorização. A lista da associação não é para vender, nem para a fofoca: é para servir. E lembre-se de que a IA vê o que você põe: uma base de dados com dados de todos é um tesouro que exige honestidade. Bons dados, bem usados, para bons fins.

## 🔓 Ferramentas abertas
- **Airtable** (airtable.com) — a base de dados amigável com modelos, gratuita na versão básica.
- **Google Tables** (tables.google.com) — a base de dados do Google, simples e ligada à família de ferramentas que conhece.
- **Notion** (notion.so) — um espaço que combina documentos e bases de dados, com uma parte gratuita.
- **LibreOffice Base** (libreoffice.org) — a base de dados de código aberto que vive no seu computador.
- **NocoDB** (nocodb.com) — uma base de dados de código aberto que pode ter em casa.

## 🧠 Resumo e ponte
Uma base de dados é um armazém bem classificado: registos, campos e vistas, com uma IA que entende as suas perguntas. Serve para listas, pessoas, coisas e datas; a folha de cálculo para calcular. Criou, preencheu e perguntou: já sabe pôr ordem nos dados. No nível seguinte vamos descobrir a voz: ferramentas que leem, escrevem e falam, para que o computador também o ouça.
