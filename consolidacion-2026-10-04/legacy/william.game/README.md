# william.game

Juego educativo móvil con minijuegos de inglés, español y catalán, voz natural de profesora y estética arcade neo-glass. · Construido con Manus

## Stack

- Primary language: TypeScript
- Node project (`package.json` present)

## Getting started

```bash
git clone https://github.com/belentani7/william.game.git
```

```bash
npm install
npm run dev
```
