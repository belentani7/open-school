# Lista de verificación SEO

Aunque el sitio ya tiene 100% en SEO, mantener estas buenas prácticas asegura que siga siendo así.

## Fundamentos
- [ ] Título de página descriptivo y único (<title>)
- [ ] Meta descripción atractiva y dentro de 150-160 caracteres
- [ ] Uso correcto de encabezados jerárquicos (H1 solo uno por página, luego H2, H3...)
- [ ] URL amigables: legibles, sin parámetros innecesarios, guiones en lugar de guiones bajos
- [ ] Contenido original y de valor para el usuario
- [ ] Uso adecuado de palabras clave de forma natural

## Indexación y rastreo
- [ ] Archivo robots.txt presente y correctamente configurado (no bloquear recursos importantes)
- [ ] Sitemap XML enviado a Google Search Console y actualizado
- [ ] Etiqueta meta robots adecuada (index, follow) donde corresponda
- [ ] Canonical URLs implementadas para evitar contenido duplicado
- [ ] Uso de hreflang para versiones internacionales (el sitio ya tiene múltiples idiomas)

## Experiencia de usuario
- [ ] Tiempo de carga rápido (ver rendimiento)
- [ ] Diseño responsive y amigable para móviles
- [ ] Navegación clara y estructura lógica
- [ ] Uso de breadcrumbs si aplica

## Contenido estructurado
- [ ] Datos estructurados (Schema.org) donde sea relevante (por ejemplo, organización, cursos, preguntas frecuentes)
- [ ] Validado con la herramienta de prueba de datos estructurados de Google

## Seguridad y confianza
- [ ] HTTPS implementado y redirecciones de HTTP a HTTPS
- [ ] Política de privacidad y términos de servicio accesibles
- [ ] Información de contacto clara

## Enlaces
- [ ] Enlaces internos funcionando y útiles
- [ ] Enlaces externos a fuentes confiables y relevantes
- [ ] Uso de atributo rel="nofollow" o "sponsored" cuando corresponda (por ejemplo, enlaces de pago)
- [ ] Texto de ancla descriptivo

## Multimedia
- [ ] Imágenes con atributo alt descriptivo
- [ ] Videos con subtítulos o transcripción
- [ ] Archivos multimedia optimizados para web

## Revisión periódica
- [ ] Auditar con Lighthouse SEO mensualmente
- [ ] Revisar Google Search Console para errores de cobertura, usabilidad móvil, etc.
- [ ] Monitorear rankings y tráfico orgánico

---
Nota: Dado que el sitio ya obtuvo 100% en SEO, esta lista sirve como mantenimiento y mejora continua.
