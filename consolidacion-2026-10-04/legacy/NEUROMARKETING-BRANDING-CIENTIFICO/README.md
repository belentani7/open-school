# Neuromarketing y Branding Científico

**La Arquitectura Visual de la Marca**

Documento de investigación completo sobre neuromarketing y branding científico. Cómo la neurociencia, la psicología cognitiva y la percepción visual determinan el éxito de tu identidad corporativa.

## Contenido

- **12 capítulos** de investigación profunda
- **45+ estudios peer-reviewed** citados y referenciados
- **20+ diagramas** visuales y esquemas explicativos
- **Framework NEUROBRAND** para creación de marcas basado en neurociencia
- **Caso de estudio completo**: Restaurante Dragón de Jade 龍玉

## Uso

Abre `index.html` en cualquier navegador moderno. El documento es una página web autónoma sin dependencias externas (salvo fuentes Google Fonts).

### Localmente

```bash
# Con Python
python -m http.server 8000

# Con Node.js (npx)
npx serve .

# Con PHP
php -S localhost:8000
```

### Despliegue

El archivo `index.html` puede subirse directamente a cualquier hosting estático: GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.
