# Changelog

Todas las novedades notables de este proyecto se documentan en este archivo.
El formato se basa en [Keep a Changelog](https://keepachangelog.com/es/1.1.0/),
y este proyecto adheres al [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-06-01

### Added

- Documento de investigación completo: Neuromarketing y Branding Científico
- 12 capítulos de investigación profunda sobre neuromarketing
- 45+ estudios peer-reviewed referenciados
- 20+ diagramas visuales y esquemas explicativos
- Framework NEUROBRAND para creación de marcas basado en neurociencia
- Caso de estudio completo: Restaurante Dragón de Jade 龍玉
- HTML5 semántico con CSS3 (sin frameworks externos)
- Fuentes tipográficas: Playfair Display, Inter, JetBrains Mono (Google Fonts)
- Schema.org structured data (Article)
- Open Graph y Twitter Card meta tags
- PWA manifest para instalación como aplicación
- Accesibilidad: roles ARIA, contraste WCAG AA
- CI workflow con GitHub Actions
- Scripts de desarrollo con `npx serve`
