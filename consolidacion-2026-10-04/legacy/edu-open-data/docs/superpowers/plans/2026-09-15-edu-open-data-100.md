# edu-open-data al 100% — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Llevar los 8 portales educativos Belentani al 100% (cobertura completa, 0 enlaces rotos, 8/8 publicados) y persistir todo en GitHub.

**Architecture:** Se ejecuta el pipeline existente de `edu-open-data` (registro → verificación → enriquecimiento → cobertura → publicación → sonda) ampliando el registro con las candidatas aprobadas y los temas de cada portal, corrigiendo el deploy de los 2 caídos.

**Tech Stack:** Python 3.11 (stdlib), pytest, gh CLI, git, Vercel/GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-15-edu-open-data-100-design.md`

## Global Constraints

- Idiomas en orden fijo: `["pt", "es", "en", "ca"]` (PT > ES > EN > CA).
- Fuentes: solo sin API key + licencia determinada.
- NO cambiar visibilidad de repos privados.
- Todo script es idempotente y re-ejecutable.
- Commits frecuentes; no commitear secretos (tokens van a env, nunca al repo).

- [ ] **Step 1: Escribir test que exige registro ampliado**

```python
import json
from pathlib import Path

def test_registro_supera_300_fuentes():
    idx = json.loads(Path("registry/index.json").read_text(encoding="utf-8"))
    assert idx["count"] >= 300

def test_toda_fuente_tiene_area_y_licencia():
    for area in ["idiomas","academico","civico_derechos","ciberseguridad",
                 "ux_diseno","patrimonio_arte","ciencia_salud","datos_pais"]:
        data = json.loads(Path(f"registry/{area}.json").read_text(encoding="utf-8"))
        for f in data["sources"]:
            assert f.get("license"), f"sin licencia: {f.get('id')}"
```
