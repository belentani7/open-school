# Contribuir

## Proponer un recurso

Incluye nombre, URL oficial, zona, coste, público, motivo de inclusión y fecha de comprobación. No envíes testimonios, casos personales, documentos ni fotografías sin licencia.

## Criterios de aceptación

- Utilidad directa para personas LGTBIQ+ migrantes o visitantes.
- Fuente oficial o prestador identificable.
- Descripción neutral y comprobable.
- Costes, edad y riesgos relevantes visibles.
- Acceso cultural legal; sin enlaces de descarga no autorizada.
- Traducción crítica revisada por una persona competente antes de marcarla como completa.

## Verificación

```powershell
npm run news:update
npm test
```

Cada cambio debe mantener navegación por teclado, contraste WCAG AA, movimiento reducido y uso sin JavaScript para los teléfonos esenciales.
