# Juegos educativos

> Indice educativo: [INDICE-EDUCATIVO.md](../../../INDICE-EDUCATIVO.md)

## Que son

Cinco juegos en Python para aprender **jugando**. Estan pensados para quien empieza: la
mecanica es sencilla y el contenido es el que hace falta para el dia a dia.

## Los cinco juegos

| Archivo | Que trabaja |
|---|---|
| `juego_trilingue.py` | Vocabulario en tres idiomas a la vez |
| `juego_falsos_amigos.py` | Falsos amigos entre idiomas (los errores que todos cometen) |
| `juego_catalan.py` | Catalan: vocabulario y uso |
| `juego_mate_escape.py` | Matematicas como escape: calculo y logica |
| `juego_super_quiz.py` | Quiz general de repaso |

## Como se ejecutan

```bash
python juego_trilingue.py
```

Solo necesitan Python. Sin instalacion, sin dependencias, sin conexion.

## Por que juegos

Un juego no da miedo. Quien no se atreve con un curso si prueba un juego, y el juego ensena
lo mismo. Es la puerta de entrada mas baja que existe.
