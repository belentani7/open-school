# Module 6: Education with AI — Level 17
## Language: EN · Difficulty: Branch
## Estimated time: 3 hours

## 🎯 Level objective
- Understand why images make an educational video clearer and more beautiful.
- Learn to ask AI to describe which image goes with each scene.
- Learn about open tools to generate images with AI.
- Choose suitable images, without fear of getting it wrong.
- Have the image track of our video ready for editing.

## 📖 Essential vocabulary
| Term | Explanation in simple words |
|---|---|
| Image | An illustration, photo or drawing that accompanies the text. |
| To illustrate | Putting images to an idea, like putting photos in an album. |
| Image generator | An AI tool that draws from a description. |
| Description | The text we give the generator so it draws what we want. |
| Style | The look of the image: photo, drawing, old, modern. |
| Image track | The set of images of our video, in order. |

## 📚 Main lesson
An educational video with only voice is like a letter without photos: it does its job, but it does not move you. Images are the eyes of the video: they show what the voice tells and fix it in memory. When we see and hear at the same time, we remember much better, as we already know. That is why, after the script and the voice, it is the images' turn.

The good news is that today artificial intelligence also draws. We describe what we want and it creates the image. It is like commissioning a painting from a painter: we tell them the scene and they paint it. These tools are free and are used from the browser, without installing anything.

Which image goes with each scene? That is decided by us, with AI's help. First we look at our script and see how many scenes it has: introduction, three parts and closing. Each scene needs an image. It is like decorating a house: each room needs its painting.

To choose well, we ask AI: "My script has these scenes [we paste them]. Tell me which image goes with each one and how to describe it for an image generator". AI returns a list of descriptions. It is like having a decorator who tells us which painting to put on each wall.

A good description for a generator says three things: what is seen, in what style and in what setting. For example: "A kitchen table with flour and freshly made bread, realistic photo style, warm morning light". With that description, the generator knows what to paint. The more detailed the description, the better the image.

Style is very important. For a children's video, we can ask for "cheerful drawing with vivid colours". For a history video, "old photo in sepia tones". For a cooking video, "realistic photo". Style gives unity to the video: all images must look like they are from the same world, like tableware from the same collection.

When we have the descriptions, we run them through the image generator one by one. Each description produces an image. If we do not like the first one, we change something in the description and generate another. It is like trying recipes until we find the one we like most: patience and trials.

You do not need to be an artist to judge whether an image is good. We ask ourselves: is it understandable? Is it related to the scene? Is the style what we want? If the three answers are yes, the image works. Beauty is the prize, but clarity is the requirement.

We can ask the generator for "no text", so the image has no letters that clash. Video images usually go without words: the words are provided by the voice. A clean, text-free image integrates better into the video, like a canvas without distracting signatures.

Images can also be simple and abstract if the topic is hard to draw. For concepts like "memory", we ask for something symbolic: "an old key on a table". The image does not have to be literal: it can suggest the idea. It is like using a visual metaphor.

AI image tools have their limits: sometimes they draw strange things, like hands with too many fingers. If we see something odd, we generate again or adjust the description. It is fine: it is part of the process, like when a seam comes unstitched and it is sewn again.

We save the chosen images in the "My materials" folder, in order: image 1 for scene 1, image 2 for scene 2, and so on. That order is the image track of our video. When the editing comes, we will only have to place them in that order next to the voice.

Images are also useful for other materials: for the sheet from level 14, for a presentation, for an invitation. Learning to generate images is a gift we will use well beyond this video. It is a new window to express our ideas.

In this level we will complete the third station of the pipeline: the image track. We will ask AI for the descriptions, generate each image, review it and save it in order. With script, voice and images, the video is almost ready for editing.

## 🛠️ Guided activity
Step 1: Open your script from level 15 and count its scenes (introduction, parts, closing).
Step 2: Ask AI: "Tell me which image goes with each scene of this script and how to describe it for an image generator". Paste the script.
Step 3: Review the list of descriptions. Do they represent each scene well?
Step 4: Open your free image generator (the one your teacher indicates).
Step 5: Copy the first description and generate the image.
Step 6: Look at the image: is it understandable? Is it the style you want? If not, adjust the description and generate another.
Step 7: Repeat with each scene until you have one image per scene.
Step 8: Save the images in order in your "My materials" folder, calling them image-1, image-2, image-3...

## ✍️ Self-assessment exercises
1. Why are images important in an educational video? a) Because they show what the voice tells and fix memory. b) Because they fill time. c) They do not matter.
2. How does AI get an image? a) By drawing from a description. b) By copying from TV. c) By photographing.
3. What do we say in a good description? a) What is seen, in what style and in what setting. b) Only the colour. c) Nothing.
4. If the image comes out odd, what do we do? a) We adjust the description and generate another. b) We leave it. c) We give up.
5. Where do we save the video's images? a) In the "My materials" folder, in order. b) Anywhere. c) We do not save them.

Answers: 1-a, 2-a, 3-a, 4-a, 5-a.

## ⚖️ Ethical dimension
- AI-generated images are creations: use them with respect and say an AI made them if appropriate.
- Do not generate fake images of real people: that can harm and deceive.
- Review each image before using it: it is your responsibility that it contains nothing offensive or wrong.
- Do not imitate the style of living artists to impersonate their work: create your own images.
- Images serve to teach and bring joy, never to lie or hurt.
