# Módulo 7: Projetos Comunitários — Nível 23
## Idioma: PT · Dificuldade: Fruto
## Tempo estimado: 3 horas

## 🎯 Objetivo do nível
- Aprender o que é a sustentabilidade de um projeto comunitário.
- Conhecer as formas de garantir recursos sem depender de ninguém.
- Cuidar da equipa para que o projeto não se esgote.
- Preparar o futuro do projeto para além das pessoas que o começaram.
- Construir um projeto que dure e dê fruto durante muitos anos.

## 📖 Vocabulário essencial
| Termo | Explicação em palavras simples |
|---|---|
| Sustentabilidade | A capacidade de o projeto se manter sozinho, ao longo do tempo. |
| Recursos | O que o projeto precisa: dinheiro, materiais, tempo e pessoas. |
| Autofinanciamento | Ganhar o próprio dinheiro, sem depender de ninguém. |
| Rotatividade | Renovar as pessoas e as tarefas para que o projeto respire. |
| Continuidade | Passar o conhecimento e as responsabilidades às próximas gerações. |
| Legado | Aquilo que o projeto deixa para a comunidade, para sempre. |

## 📚 Lição principal
O projeto cresceu: tem raízes, tronco, ramos e copa. Agora aprendemos a fazer durar: a sustentabilidade. Um projeto que dura não é o que tem mais sorte: é o que sabe cuidar dos seus recursos, das suas pessoas e do seu futuro.

A sustentabilidade é a capacidade de o projeto se manter sozinho, ao longo do tempo. Um projeto sustentável não vive à custa do entusiasmo de uma semana nem do sacrifício de uma pessoa. Vive do que cultiva: dos seus recursos, da sua equipa e da sua memória.

Os recursos são o que o projeto precisa para viver: dinheiro, materiais, tempo e pessoas. Sem recursos, o melhor projeto morre; com recursos mal cuidados, também. A sustentabilidade ensina-nos a conhecer os nossos recursos, a gastá-los com conta e a renová-los a tempo.

O dinheiro é um dos recursos e precisa de cuidado. Há o autofinanciamento: o projeto ganha o seu próprio dinheiro. Uma pequena venda, uma oficina, uma ajuda por um serviço. Não é vergonha: é dignidade. Um projeto que ganha o que gasta não depende da boa vontade de ninguém.

Os materiais também pedem cuidado: as ferramentas, as sementes, o espaço. O que se cuida, dura; o que se descuida, estraga-se. Uma ferramenta guardada, uma semente conservada, uma sala arranjada a tempo: pequenos gestos que fazem o projeto durar anos.

O tempo é um recurso precioso, e as pessoas também. A sustentabilidade não pode apagar as pessoas: se a equipa se esgota, o projeto morre. Por isso, as tarefas rotativas: ninguém faz sempre a mesma coisa, ninguém carrega tudo sozinho. A rotatividade renova a equipa e reparte a carga.

A continuidade é o coração da sustentabilidade. O conhecimento não pode ir embora com quem o criou: tem de passar a quem vem. Quem sabe plantar, ensina a plantar; quem sabe liderar, prepara quem lidera. O conhecimento partilhado não se divide: multiplica-se.

O projeto também precisa de descansar. Uma comunidade que não para, cansa-se; um projeto que não descansa, estraga-se. Os períodos de pausa não são preguiça: são parte da sustentabilidade. Quem sabe parar, também sabe continuar.

A sustentabilidade olha para o longo prazo. Não pergunta apenas "o que fazemos este ano?", pergunta "o que deixaremos daqui a dez anos?". O legado é aquilo que o projeto deixa para a comunidade, para sempre: o conhecimento, a confiança, o hábito de se juntarem e decidirem juntos.

Um projeto sustentável é como uma árvore de fruto: precisa de raízes, de terra, de água e de quem a cuide. Não dá fruto todos os dias, mas dá todos os anos, e alimenta muitas pessoas. O que aprendemos a cultivar com paciência, dá-nos fruto com generosidade.

A sustentabilidade também é de todos: não é o problema de uma pessoa. Cada participante é parte do que faz durar: cuidar de uma ferramenta, ensinar um gesto, chegar a tempo. Um projeto sustentável é a soma de mil pequenos cuidados que ninguém vê.

Neste nível vamos olhar para os nossos recursos e para o nosso futuro: como garantimos o que precisamos, como cuidamos das nossas pessoas e como deixamos a nossa memória. Vamos construir um projeto que não acabe quando acabar o entusiasmo: um projeto que dê fruto, ano após ano, para a nossa comunidade.

## 💡 Exemplos práticos
1. **O autofinanciamento.** A comunidade organiza uma pequena venda de pão duas vezes por mês. O que ganham paga as sementes e as ferramentas. O projeto já não depende de ninguém para o essencial.
2. **A rotatividade das tarefas.** O mesmo participante fazia sempre os cartazes. Agora as tarefas rodam a cada três meses: todos aprendem e ninguém se esgota. Quando alguém falta, há sempre quem saiba.
3. **A memória passada.** O participante mais antigo ensina aos mais novos a podar as árvores e a conservar as sementes. O seu conhecimento não se perde com ele: fica plantado nos outros.

## 🛠️ Atividade guiada
Passo 1: Faze a lista dos recursos do projeto: o que tens e o que falta.
Passo 2: Pensa no autofinanciamento: o que pode o projeto ganhar sozinho?
Passo 3: Cuida de um material esta semana: arranja, guarda, conserva.
Passo 4: Revisa as tarefas: quem carrega mais? Rotaciona.
Passo 5: Ensina a alguém um gesto que sabes fazer bem.
Passo 6: Pensa no descanso: quando vai a equipa parar, sem culpa?
Passo 7: Escreve o legado: o que querem deixar daqui a dez anos?

## ✍️ Exercícios de autoavaliação
1. O que é a sustentabilidade? a) O projeto viver só de entusiasmo. b) A capacidade de o projeto se manter sozinho ao longo do tempo. c) Um projeto que dura uma semana.
2. O que é o autofinanciamento? a) Depender de donativos. b) Ganhar o próprio dinheiro. c) Não gastar nada.
3. Para que serve a rotatividade? a) Para ninguém aprender. b) Para repartir a carga e renovar a equipa. c) Para complicar.
4. O que é a continuidade? a) Passar o conhecimento a quem vem. b) Guardar o conhecimento só para os fundadores. c) Deixar o projeto acabar.
5. O que é o legado? a) O que se gasta. b) O que o projeto deixa à comunidade para sempre. c) Uma dívida.

Respostas: 1-b, 2-b, 3-b, 4-a, 5-b.

## ⚖️ Dimensão ética
- O projeto vive dos seus recursos, mas não à custa das suas pessoas.
- Ganhar o próprio dinheiro é dignidade, não vergonha.
- O conhecimento partilha-se: ninguém leva o que aprendeu sozinho.
- O descanso é parte do trabalho.
- O legado é de todos: o projeto deixa mais do que aquilo que consumiu.

## 🔓 Ferramentas abertas

|---|---|---|
| Lista de recursos | Saber o que o projeto tem e o que falta | No caderno do plano |
| Ronda de rotatividade | Repartir e renovar as tarefas | Nas reuniões |
| Horas de partilha | Ensinar o que cada um sabe | No dia a dia |
| Calendário de descanso | Parar sem culpa, para durar | No caderno do plano |

## 🧠 Resumo e ponte
A sustentabilidade faz durar o projeto: cuidar dos recursos, ganhar o próprio sustento, rotacionar as tarefas, partilhar o conhecimento e preparar o legado. Um projeto que se cuida, dá fruto durante anos. No próximo nível aprenderemos a avaliação participativa: olhar o caminho feito, aprender com os erros e celebrar o que foi alcançado.
