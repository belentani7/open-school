# Module 5: Automation and Integration — Level 01
## Language: EN · Difficulty: Seed
## Estimated time: 1 hour

## 🎯 Level objective
- Recognize the repetitive tasks we do every day at home and at work.
- Tell which of those tasks can be automated and which cannot.
- Learn to describe a task as a sequence of steps.
- Choose a task of your own to automate in the coming levels.
- Understand that automating starts with observing, not programming.

## 📖 Essential vocabulary
| Term | Simple explanation |
|---|---|
| Repetitive task | A job that is done over and over the same way: paying a bill, going through your email. |
| Step | Each concrete action within a task. |
| Sequence | The order in which the steps are done. |
| Routine | A set of tasks we repeat in the same order. |
| Automatable | That can be done without a person being present. |
| Decision | A moment when we choose between several options. |

## 📚 Main lesson
In the previous level we learned that automating means making a machine do a task for us. Today we are going to take the second step: learning to look at our own life and find the tasks that repeat. Because you cannot automate what you cannot see.

Let's imagine the kitchen at home. Every morning we make coffee: grinding, adding water, turning on the coffee maker. It is the same every day. That is a repetitive task and, in fact, many coffee makers can already be programmed so the coffee is ready at a set time.

A repetitive task has three signs. First, it is done very often: every day, every week. Second, it is done the same every time: same steps, same order. Third, it needs no big decisions: you know in advance what to do. When a task has those three signs, it is a good candidate for automating.

At the office we find many repetitive tasks. Checking email every morning, saving documents in the same folder, copying data from a paper to a table, sending the same report every week. These are jobs that a programme or a well-set rule could do on its own.

But not all repetitive tasks are automated the same way. Some are very simple: setting an alarm, saving a file. Others are complicated: filling in a form with data that changes every time. The general rule is simple: if the steps are always the same, the machine can learn them; if the steps change depending on what you decide, a person is needed.

To automate a task you first have to describe it. Like when we teach someone to cook a dish: first we explain it step by step. Let's take "doing the weekly shopping" as an example. The steps could be: making the list, going to the shop, buying, paying, bringing it home. Some of those steps are automatic (the list with a template), others need a person (choosing the fresh fruit).

You have to avoid the trap of automating what is not worth it. If we do a task once a year, it is not worth the effort. If it takes ten seconds, neither. What is worth automating is what we do a lot and takes time. It is like in the kitchen: we buy a blender because we blend often, not for a single use.

Another important thing: many repetitive tasks are really the sum of several small ones. "Paying the water bill" is: opening the email, finding the bill, opening the bank, making the transfer, saving the receipt. Each step can be automated separately. Starting with a single step is already a great advance.

When we observe our own week, we will find tasks we do without thinking. Those are the best ones to start with: we already know them, we already know how they are done and we already have the order. We just need to write them down and ask the machine to repeat them.

Don't worry. This module is like learning to sow: first you prepare the soil, then you choose the seed, and in time you harvest. Today we only prepare the soil: we look, we write down and we choose. The rest will come on its own.

A suggestion: this week, every time you do a task for the second time, ask yourself quietly: "does this repeat?" If the answer is yes, write it down. You will see the list grow on its own. And from that list your first automation will come out.

## 💡 Practical examples
1. **Work email.** Luisa goes through fifty emails every morning and most are notifications she doesn't need to read. In the next levels she will learn to filter them so only the important ones arrive.
2. **The shopping list.** Ramón uses the same list every week. By saving it as a template on his phone, he doesn't have to write it again: he just ticks off what is no longer needed.
3. **The weekly report.** Carmen copies the same numbers onto a sheet every Friday. It is a repetitive task perfect for automating later in this module.

## 🛠️ Guided activity
Step 1: Get your paper from level 0 with the two columns and add a third one: "Tasks that repeat".
Step 2: Think of a normal week and write down five tasks you always do the same way: setting the alarm, checking your email, watering the plants, paying a bill, making coffee.
Step 3: Choose one of those tasks and write its steps in order, numbered from 1 to 4 or 5. For example, paying the water bill: 1) open the email, 2) read the bill, 3) open the bank, 4) pay, 5) save the receipt.
Step 4: Underline in red the steps that are always the same and in blue the ones that require deciding.
Step 5: Think about whether that task passes the three signs: is it done often? always the same? without big decisions? Write yes or no for each one.
Step 6: Keep this description. It is your "task file" and we will use it in the next levels to build the automation.
Step 7: Repeat steps 2 to 6 with an office task or a task from your job, if you have one.

## ✍️ Self-assessment exercises
1. Which is a sign that a task can be automated? a) That it is done once a year. b) That it is done often, always the same and without big decisions. c) That it is very difficult.
2. What is the first thing to do to automate a task? a) Buy a programme. b) Describe it step by step. c) Ask for help.
3. Are a simple task and a complicated one automated the same way? a) Yes, always. b) No, the simple ones are automated first. c) None of them are automated.
4. Is it worth automating a task we do once a year? a) Yes, always. b) No, it doesn't pay off the effort. c) It depends on the colour.
5. What is a repetitive task? a) A job that is done over and over again in the same way. b) A very fun job. c) A one-off job.

Answers: 1-b, 2-b, 3-b, 4-b, 5-a.

## ⚖️ Ethical dimension
- Observing your own tasks is good; observing other people's tasks to save them work can be useful, but ask before changing how another person works.
- Don't automate tasks that others enjoy doing just to be "efficient".
- If you automate a task at work, inform your team: transparency avoids surprises and mistakes.
- Writing down your routines on paper is safe; don't store passwords or sensitive data in those notes.
- Automating a task is not taking anyone's job away: it is freeing up time for more important things.
